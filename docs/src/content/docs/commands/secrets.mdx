```sh
envx secrets <command> [flags]
```

`secrets` manages the encrypted values in the workspace store. Values are organized by group and key, and are referenced from your files as `secret://<group>/<key>`. See [Secrets store](../../concepts/secrets-store/) for how the store, groups, and keypairs fit together, and [`keypair`](../keypair/) to create a group's keys.

| Command | Purpose |
| --- | --- |
| [`get`](#get) | Decrypt and print one stored secret. |
| [`set`](#set) | Encrypt and store one secret value. |
| [`delete`](#delete) | Remove one stored secret value. |
| [`encrypt`](#encrypt) | Encrypt plaintext values in the store in place. |
| [`decrypt`](#decrypt) | Decrypt stored values into plaintext in place. |

## `get`

```sh
envx secrets get <group> <key>
```

Decrypts one secret and prints its plaintext to stdout. It requires an available private key for the group and fails when none is available.

```sh
envx secrets get production database_password
DB_PASSWORD=$(envx secrets get production database_password)
```

## `set`

```sh
envx secrets set <group> <key> [plaintext]
```

Adds or updates one secret. The plaintext is read from stdin, or from a hidden terminal prompt with a length confirmation when stdin is interactive. An optional `plaintext` argument is supported for automation, but it can leak into shell history and process listings, so prefer stdin.

```sh
printf '%s' "$DB_PASSWORD" | envx secrets set production database_password
envx secrets set shared service_token
```

| Flag | Description |
| --- | --- |
| `--no-confirm` | Skip the interactive confirmation prompt. |

## `delete`

```sh
envx secrets delete <group> <key>
```

Removes one secret. The group's public key and its remaining values are preserved, so deleting a value never tears down the group's identity. Deleting a value that does not exist is an error.

```sh
envx secrets delete production database_password
```

## `encrypt`

```sh
envx secrets encrypt [--group <group>] [--key <key>]
```

Re-encrypts plaintext values in the store in place, using each group's public key. Values that are already encrypted are left untouched, so the command is safe to run repeatedly. A `--group` or `--key` that matches no stored value is an error.

```sh
envx secrets encrypt
envx secrets encrypt --group production
envx secrets encrypt --group shared --key service_token
```

## `decrypt`

```sh
envx secrets decrypt [--group <group>] [--key <key>]
```

Rewrites encrypted values in the store as plaintext in place, using each group's private key. Values that are already plaintext are left untouched. A group whose private key is unavailable is skipped with a warning, so the groups you can decrypt still succeed. A `--group` or `--key` that matches no stored value is an error.

:::danger[Never commit decrypted values]
`decrypt` writes plaintext secrets to disk. Re-encrypt with `envx secrets encrypt` before committing the store.
:::

```sh
envx secrets decrypt --group production
```

## Flags

| Flag | Applies to | Description |
| --- | --- | --- |
| `--group`, `-g` | `encrypt`, `decrypt` | Limit to one key group. Default: all groups. |
| `--key`, `-k` | `encrypt`, `decrypt` | Limit to one secret key. Default: all keys. |
| `--verbose`, `-v` | `encrypt`, `decrypt` | Print each changed secret. |
| `--no-confirm` | `set` | Skip the interactive confirmation prompt. |

Plus the [global flags](../overview/#global-flags).
