```sh
envx explain <project> [key]
```

`explain` resolves a project's environment and reports, for each key, its type, its literal value, the file it was resolved from, and a resolution status. With no key it explains every key; with a key it explains just that one.

Secret references are classified without decrypting them; pass `--reveal` to add a `RESOLVED` column with their plaintext. Source paths are relative to `envx.yaml` unless you pass `--absolute`. A value read from the [local env file](../../concepts/local-env/) shows that file as its source, and a process variable shows `(process)`.

Use `--output json` for machine-readable output. Each entry's `sourceKind` is `namespace`, `localEnv` or `process`, and `source` is empty for a process variable.

## Arguments

| Argument | Description |
| --- | --- |
| `<project>` | The project to resolve. |
| `[key]` | Optional. Explain only this key instead of all keys. |

## Examples

The examples below use the same `api` workspace:

## Flags

| Flag | Environment variable | Description |
| --- | --- | --- |
| `--output`, `-o` | | Output format: `table` (default) or `json`. |
| `--reveal` | | Decrypt secret references and show them in a `RESOLVED` column (and a `resolved` JSON field). |
| `--absolute` | | Show absolute source paths instead of paths relative to `envx.yaml`. |
| `--env`, `-E` | `ENVX_ENV` | Target environment to resolve. |
| `--require-overlays` | `ENVX_REQUIRE_OVERLAYS` | Require every overlay file to exist. |
| `--prefix` | `ENVX_PREFIX` | Prefix prepended to every key. |
| `--suffix` | `ENVX_SUFFIX` | Suffix appended to every key. |
| `--delimiter` | `ENVX_DELIMITER` | String used to join list values. |
| `--overload` | `ENVX_OVERLOAD` | Prefer file values over host variables in `{{VAR}}` substitution. |
| `--reference-pattern` | `ENVX_REFERENCE_PATTERN` | Regex overriding the `{{VAR}}` reference syntax. |

Plus the [global flags](../overview/#global-flags). The setting flags map to [settings](../../configuration/schema/#settings-2) and override the values in `envx.yaml`.
